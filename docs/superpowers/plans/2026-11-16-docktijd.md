# DockTijd Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A windowless macOS app whose Dock icon is a live clock with 10 selectable faces (5 analogue, 5 digital), chosen from the Dock right-click menu.

**Architecture:** Faces are stateless Core Graphics drawers behind a `ClockFace` protocol. A `ClockView` (NSView) is installed as `NSApp.dockTile.contentView`. A `ClockEngine` ticks on exact second or minute boundaries and calls `dockTile.display()`. `AppDelegate.applicationDockMenu` builds the face menu with cached preview images. The bundled `AppIcon` is the "sleeping" graphic shown when the app is not running.

**Tech Stack:** Swift 6 (strict concurrency), AppKit, Core Graphics, Swift Testing, ServiceManagement (`SMAppService`). XcodeGen (dev-time only) to generate the `.xcodeproj`. No runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-11-16-docktijd-design.md`

## Global Constraints

- Swift 6 language mode, strict concurrency on; latest Xcode and macOS SDK; deployment target macOS 15.0 (my call, builder may raise).
- Native AppKit only; no third-party runtime dependencies.
- No windows, no menu-bar item (`LSUIElement` = NO, so the Dock icon exists).
- Exactly 10 faces: 5 analogue (ids `classic`, `minimalDark`, `railway`, `aqua`, `retroGold`) and 5 digital (ids `boldMono`, `neon`, `flip`, `lcd`, `pill`).
- Seconds-driven redraw only for faces with `showsSeconds == true`; otherwise once per minute.
- Time is read from `Date` on every tick (no accumulated counters).
- Selected face id is persisted in `UserDefaults` under key `selectedFaceID`.
- Digital faces follow the system 12/24-hour setting.
- Idle CPU near zero between ticks; the timer pauses on system sleep.

## Review Focus

- Wall clock changes (manual set, DST shift, timezone change) while running: the next tick shows the right time (listen for `NSSystemClockDidChange`, reschedule).
- Sleep/wake: no stale time after wake; the timer is rescheduled on `NSWorkspace.didWakeNotification`.
- Stored face id that no longer exists (or garbage): fall back to `classic`, no crash.
- 12-hour locale at 00:xx and 12:xx: shows 12, not 0; AM/PM correct.
- Tiny render sizes (menu previews, ~32pt) and Retina 2x/3x: faces must not crash or draw outside their bounds.
